# 💼 Job Application Tracker

## About the Project

I built this project to improve my full-stack software development skills by creating something practical that I could continue building over time.

The application is designed to keep track of job applications in one place instead of using spreadsheets or notes. Users can add, update, view and delete applications while keeping important information like the company, position, recruiter details and application status organised.

This project has also helped me gain hands-on experience with React, Express, Node.js, MariaDB, Git and GitHub while following a real development workflow.

---

## Features

- Add new job applications
- View all applications
- Update existing applications
- Delete applications
- Store recruiter information
- Track application status
- REST API built with Express.js
- MariaDB database integration

## Getting Started

Clone the repository

```bash
git clone https://github.com/KyleL301/job-application-tracker.git
```

Install backend dependencies

```bash
cd backend
npm install
```

Install frontend dependencies

```bash
cd ../frontend
npm install
```

Start the backend

```bash
npm run dev
```

Start the frontend

```bash
npm run dev
```
